# SMP Server Stats Persistence Implementation Plan

**Goal:** SMP server stats survive crashes: periodic saves to Postgres (Postgres mode) or an atomically written file (memory mode), with active-queue sets saved incrementally.

**Architecture:** A new `Simplex.Messaging.Server.StatsStore` module loads and saves `ServerStatsData` through a file or a database backend. `PeriodStats` tracks hashes added since the last save so the database receives only new hashes. `Server.hs` restores on start, recomputes store counts, saves on a timer, around the daily rollover, and on shutdown, all under `savingLock`.

**Tech Stack:** Haskell (GHC 9.6.3), postgresql-simple, hspec, cabal with `-fserver_postgres`.

**Spec:** `plans/2026-10-23-server-stats-persistence-design.md`

## Global Constraints

- Build and test with `-fserver_postgres`; PostgreSQL must run on `localhost:5432` (see `contributing/PROJECT.md`). Use the same flags for every command so cabal does not rebuild between steps: `cabal build -fserver_postgres --ghc-options=-O0`, `cabal test -fserver_postgres --ghc-options=-O0 --test-show-details=streaming --test-option=--match="..."`.
- Never wait with `sleep`/polling loops; run commands in the foreground with a timeout.
- Format changed Haskell with fourmolu (`fourmolu -i <file>`); files with CPP (`Server.hs`, `Env/STM.hs`, `StatsStore.hs`, test files with CPP) are formatted by fragment, matching surrounding style.
- No new compiler warnings (library uses `-Weverything`); imports used only under `dbServerPostgres` go inside the `#if defined(dbServerPostgres)` block.
- Comments only where code cannot state it (ordering, invariants); no plan/spec references in code.
- Commit messages: `<scope>: <subject>`, max 50 chars, imperative, no body, no co-author.
- `server_stats_queues.period_set` values are fixed: 1 msg day, 2 msg week, 3 msg month, 4 ntf day, 5 ntf week, 6 ntf month.
- Column order of `server_stats` in the migration, `statsFields`, and the `FromRow StatsRow` instance must be identical.
- Default save interval 300 seconds, INI key `[STORE_LOG] stats_save_interval`.

**User decisions (already made):**
- Postgres-mode servers store stats in a Postgres table; the existing file is imported once when the database has no stats row, then renamed to `.bak`; afterwards the database is the only source and corrections are done with SQL.
- One `BIGINT` column per persisted metric (not a text blob or JSONB).
- Active-queue sets are stored incrementally in a hash table (`server_stats_queues`), only new hashes inserted per save, rows of reset sets deleted.
- Memory-mode servers save the file periodically with temp file + rename and no longer rename it to `.bak` at startup.
- Scope: the metrics persisted in the file today, plus recomputing `qCount`/`msgCount`/`ntfCount` from the store on every start.
- Save interval is an INI option with default 300 seconds, active only when `log_stats = on`.

```haskell
data PeriodStats = PeriodStats
  { day :: IORef IntSet,
    week :: IORef IntSet,
    month :: IORef IntSet,
    pendingPeriods :: Maybe PendingPeriods
  }

-- hashes added and sets reset since the last successful save
data PendingPeriods = PendingPeriods
  { pendingDay :: IORef PendingHashes,
    pendingWeek :: IORef PendingHashes,
    pendingMonth :: IORef PendingHashes
  }

data PendingHashes = PendingHashes
  { pendingReset :: Bool,
    pendingAdded :: IntSet
  }
  deriving (Eq, Show)

newPeriodStats :: IO PeriodStats
newPeriodStats = newPeriodStats_ Nothing

newPendingPeriodStats :: IO PeriodStats
newPendingPeriodStats = do
  pendingDay <- newIORef noPendingHashes
  pendingWeek <- newIORef noPendingHashes
  pendingMonth <- newIORef noPendingHashes
  newPeriodStats_ $ Just PendingPeriods {pendingDay, pendingWeek, pendingMonth}

newPeriodStats_ :: Maybe PendingPeriods -> IO PeriodStats
newPeriodStats_ pendingPeriods = do
  day <- newIORef IS.empty
  week <- newIORef IS.empty
  month <- newIORef IS.empty
  pure PeriodStats {day, week, month, pendingPeriods}

noPendingHashes :: PendingHashes
noPendingHashes = PendingHashes {pendingReset = False, pendingAdded = IS.empty}

takePendingHashes :: IORef PendingHashes -> IO PendingHashes
takePendingHashes ref = atomicModifyIORef' ref (noPendingHashes,)

restorePendingHashes :: IORef PendingHashes -> PendingHashes -> IO ()
restorePendingHashes ref taken = atomicModifyIORef'_ ref $ mergePendingHashes taken

mergePendingHashes :: PendingHashes -> PendingHashes -> PendingHashes
mergePendingHashes (PendingHashes r hs) (PendingHashes r' hs') = PendingHashes (r || r') (IS.union hs hs')
```

```haskell
periodStatCounts :: PeriodStats -> UTCTime -> IO PeriodStatCounts
periodStatCounts ps ts = do
  let d = utctDay ts
      (_, wDay) = mondayStartWeek d
      MonthDay _ mDay = d
      pending_ = pendingPeriods ps
  dayCount <- periodCount 1 (day ps) (pendingDay <$> pending_)
  weekCount <- periodCount wDay (week ps) (pendingWeek <$> pending_)
  monthCount <- periodCount mDay (month ps) (pendingMonth <$> pending_)
  pure PeriodStatCounts {dayCount, weekCount, monthCount}
  where
    periodCount :: Int -> IORef IntSet -> Maybe (IORef PendingHashes) -> IO Text
```

```haskell
  deriving (Bounded, Enum, Eq, Ord, Show)

periodSetId :: PeriodSet -> Int16
periodSetId = \case
  PSMsgDay -> 1
  PSMsgWeek -> 2
  PSMsgMonth -> 3
  PSNtfDay -> 4
  PSNtfWeek -> 5
  PSNtfMonth -> 6

  toField = toField . periodSetId

periodSetHashes ServerStatsData {_activeQueues = q, _activeQueuesNtf = n} = \case

  PSMsgWeek -> _week q
  PSMsgMonth -> _month q
  PSNtfDay -> _day n
  PSNtfWeek -> _week n
  PSNtfMonth -> _month n

  PSMsgDay -> pendingDay <$> pendingPeriods activeQueues
  PSMsgWeek -> pendingWeek <$> pendingPeriods activeQueues
  PSMsgMonth -> pendingMonth <$> pendingPeriods activeQueues
  PSNtfDay -> pendingDay <$> pendingPeriods activeQueuesNtf

  PSNtfMonth -> pendingMonth <$> pendingPeriods activeQueuesNtf

      [] -> pure Nothing
```

```haskell
serverStatsStore :: M s (Maybe StatsStore)
serverStatsStore = do
  ms <- asks msgStore_
  fmap (statsStore ms) <$> asks (serverStatsBackupFile . config)
  where
    statsStore :: MsgStore s -> FilePath -> StatsStore
    statsStore = \case
      StoreMemory _ -> StatsFile
#if defined(dbServerPostgres)
      StoreDatabase ms -> StatsDB (PQ.dbStore $ queueStore ms)
#endif

saveServerStats :: M s ()
saveServerStats = do
  ss <- asks serverStats
  serverStatsStore >>= mapM_ (liftIO . (`saveStats` ss))

restoreServerStats :: forall s. MsgStoreClass s => Maybe MessageStats -> MessageStats -> M s ()
restoreServerStats msgStats_ ntfStats = do
  s <- asks serverStats
  serverStatsStore >>= mapM_ (liftIO . tryAny . loadStats >=> restore s)
  st <- asks msgStore
  EntityCounts {queueCount} <- liftIO $ getEntityCounts @(StoreQueue s) $ queueStore st
  liftIO $ do
    writeIORef (qCount s) queueCount
    writeIORef (msgCount s) $ maybe 0 storedMsgsCount msgStats_
    writeIORef (ntfCount s) $ storedMsgsCount ntfStats
    atomicModifyIORef'_ (msgExpired s) (+ maybe 0 expiredMsgsCount msgStats_)
    atomicModifyIORef'_ (msgNtfExpired s) (+ expiredMsgsCount ntfStats)
  where
    restore s = \case
      Right (Just d) -> liftIO (setServerStats s d) >> logNote "server stats restored"
      Right Nothing -> pure ()
      Left e -> do
        logError $ "error restoring server stats: " <> tshow e
        liftIO exitFailure
```
